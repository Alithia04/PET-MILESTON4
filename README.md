# PET-MILESTON4
This project is part of PET361 Milestone 4 assignment. It demonstrates a locally developed web application inspired by the AltoroMutual sign-in page.

The project focuses on login functionality, database management and intoductory security demonstrations invologing SQL injection and Cross-Site Scripting (XSS), using fictional client data. 

## NB: This project is intended for local educational use only. It must not be deployed publicly or used with real banking credentials. 
# Objectives
* Develop an offline sign-in interface inspired by AltoroMutal.
* Create a database containing dive fictional client records.
* Demonstrates SQL injection and XSS concepts in a controlled training environment
* Document the developed process, testing and results.

# Technologies Used
The project uses the following tools, where application to the actual implementation:
* XAMPP - local web server environmnet
* PHP - server-side processing
* HTML -page structure
* Css- interdace styling
* MySQL - database management
* phpMyAdmin - database admin

# Database
The database contains 5 fictional client records. The fields and database structure should match the actual implementation
NO REAL CUSTOMER INFORMATION OR BANKING CREDNETIALS SHOULD BE USED!!

## Security Demonstration 
# SQL Injection
A controlled demonstration illustrates the concept of SQL injection using fictional training data. The observed result should be documented accurately, together with screenshots  of the implementation and test

# Cross-Site Scripting
A harmless local demonstration illustrates the XSSS concept. The project should not collect or transmit password, cookies, session tokens, or other sensitive information. 

# Running the project Locally 
if the application uses XAMPP, PHP< and MySQL:
1. Open the XXAMPP Control Panel.
2. Start Apache and MYSQL.
3. Place the project folder inside the htdocs directory.
4. Open the phpMyAdmin and create or import the database using the actual project configuration.
5. Open the local project in your browser usng it's localhost address.
6. Test the login page and security demonstrations
7. Stop the local service when finished

# Testing and Evidence

* The local login page
* The database and five fictional records
* Successful and unsuccessful login attempts.
* The SQL-injection demonstration and its actual result
* The XSS demonstration and its actual result
